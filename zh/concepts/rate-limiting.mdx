## 什么是速率限制

Mellowtel 自动限制单个设备（“节点”）将接受和处理的请求数量。这个限制是在 SDK 内部强制执行的。你不需要配置它，行为不当的合作伙伴也无法从外部提高它。

## 为什么重要

共享带宽不应该减慢用户的应用程序或连接速度。如果一个节点处理无限请求，使用慢速网络的用户会感受到影响。速率限制是保护这一承诺的机制，这就是为什么你可以将 Mellowtel 提供给真实用户，而无需担心关于“浏览器感觉慢”的支持工单。

## 工作原理

每个请求都在一个沙盒化、无凭证的窗口中运行（参见[隐私](/concepts/privacy)）。由于请求与用户会话隔离，唯一对用户体验重要的因素是*运行的数量*，而这正是速率限制所控制的。

当前的限制根据以下因素变化：

- **带宽速度**：较慢的连接接收较少的请求。
- **地理位置**：容量在区域间平衡。
- **整体网络可用性**：当全球需求较低时，SDK 会退避。

<Note>
**待办事项：** 一旦确定，记录具体数字（请求/分钟上限、地理层级、带宽阈值）。目前，限制是有意适应性的，并未通过公共 API 公开。
</Note>

## API 表面

没有可调用的速率限制 API。节流是内部的，并且始终开启。你无法禁用它，也不需要检查它。如果你认为速率限制在你的集成中引发了问题，[在 GitHub 上提交问题](https://github.com/mellowtel-inc/)或在 [Discord](https://discord.com/invite/txAZp4MSDe) 上联系我们。
